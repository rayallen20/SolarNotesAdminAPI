POST /v1/book/options

按天体读取书籍选项

管理员在目录管理页选定天体后，下拉框需要该天体的全部书籍，包括隐藏书籍和尚未导入目录的书籍。选项显示书名，选中后用书籍 ID 请求目录树。

目录管理原型 · 接口设计第 ② 项

接口约定

客户端先通过 GET /v1/planet/list 获得天体 ID，再提交以下请求。沿用管理员 Bearer 鉴权，设置 Content-Type: application/json。雪花 ID 在 JSON 中使用十进制字符串，sort 使用 JSON 整数。

JSON请求体 
{
  "planet": {
    "id": "2123435429930733568"
  }
}
HTTP 200同一天体下有两本书 
{
  "code": 200,
  "message": "success",
  "data": {
    "books": [
      {
        "id": "2123435620763176960",
        "title": "MySQL是怎样运行的",
        "sort": 1,
        "display_status": "visible"
      },
      {
        "id": "2123435620763176961",
        "title": "查询优化笔记",
        "sort": 3,
        "display_status": "hidden"
      }
    ]
  }
}

查询按 planet_id 过滤，按数值 sort ASC, id ASC 排序，一次返回全部选项。现有 POST /v1/book/list 服务于全库分页表格，只在前端过滤其中一页会漏掉其他页的书。

空书单与无效选择需要分别处理。 天体存在且没有书时返回 {"code":200,"message":"success","data":{"books":[]}}。有效格式的 ID 指向不存在的天体时返回业务码 20102 和 data: {}，页面据此刷新天体选项。

定义请求与响应 DTO

planet 在请求体顶层。外层指针配合 required 校验缺失或 null；内层的 ,string 负责把字符串解码为 int64，gt=0 拦截缺失、零和负值。非法类型及超出 int64 范围的 ID 在绑定阶段返回参数错误。

新增文件param/req/v1/book/options.go 
package book

// OptionsReq 定义按天体读取书籍选项的请求.
type OptionsReq struct {
	Planet *OptionsPlanetReq `json:"planet" binding:"required"` // Planet 是当前选中的天体.
}

// OptionsPlanetReq 定义书籍选项查询需要的天体标识.
type OptionsPlanetReq struct {
	ID int64 `json:"id,string" binding:"gt=0"` // ID 是以十进制字符串提交的正整数.
}

选项 DTO 仅声明下拉框约定的四个字段。Sort 与 model.Book.Sort 一致，使用 uint32。创建接口的最小值约束仅用于写入；库中已有的 sort = 0 在读取时仍按原值返回。

新增文件param/resp/v1/book/options.go 
package book

// OptionResp 定义 data.books 中的一项.
type OptionResp struct {
	ID            string `json:"id"`             // ID 是书籍 ID 的十进制字符串.
	Title         string `json:"title"`          // Title 是下拉框显示的书名.
	Sort          uint32 `json:"sort"`           // Sort 是书籍在所属天体下的排序值.
	DisplayStatus string `json:"display_status"` // DisplayStatus 是书籍自身的 visible 或 hidden 状态.
}

在同一快照内确认天体并读取书籍

在 model/book.go 追加 (*Book).OptionsByPlanetID。沿用 ListPage 的只读可重复读事务，第一次查询仅取天体主键，第二次查询四个书籍字段。这样，即使有另一个事务同时删除天体，两次普通读取仍基于同一个 InnoDB 快照。现有文件已导入本段使用的包。

追加方法model/book.go 
// OptionsByPlanetID 返回一个天体的全部书籍选项, 按 sort 和 id 升序排列.
func (b *Book) OptionsByPlanetID(ctx context.Context, planetID int64) ([]Book, error) {
	if b == nil || ctx == nil {
		return nil, errors.New("nil book model or options context")
	}
	if planetID <= 0 {
		return nil, errors.New("book options planet ID must be positive")
	}
	if db.DB == nil {
		return nil, errors.New("database is not initialized")
	}

	tx := db.DB.WithContext(ctx).Begin(&sql.TxOptions{
		Isolation: sql.LevelRepeatableRead,
		ReadOnly:  true,
	})
	if tx.Error != nil {
		return nil, tx.Error
	}
	defer tx.Rollback()

	// 先确认天体存在, 以区分无效引用和空书单.
	var planet Planet
	err := tx.Select("id").Where("id = ?", planetID).Take(&planet).Error
	if err != nil {
		if errors.Is(err, gorm.ErrRecordNotFound) {
			return nil, PlanetNotFoundErr
		}
		return nil, err
	}

	var books []Book
	err = tx.Model(&Book{}).
		Select("id", "title", "sort", "display_status").
		Where("planet_id = ?", planetID).
		Order("sort ASC").
		Order("id ASC").
		Find(&books).Error
	if err != nil {
		return nil, err
	}
	if err := tx.Commit().Error; err != nil {
		return nil, err
	}
	return books, nil
}

用 Take 判断单个天体是否存在，用 Find 读取零到多本书。书籍查询只依赖 book.planet_id，已建的 (planet_id, sort) 唯一索引与此过滤条件匹配。两次读取均不依赖 catalogue 表。

把查询结果转换为业务实体

biz.Book.Options 接收完整请求，将模型的天体不存在错误映射为现有的 sys_error.BookPlanetNotFoundErr。当前 fillByORM 会读取已加载的 record.Planet；选项查询只加载书籍字段，因此这里直接填充四个字段。

追加方法biz/book.go 
// Options 返回当前选择的天体下可供管理员选择的书籍.
func (b *Book) Options(ctx context.Context, req *reqBook.OptionsReq) ([]Book, error) {
	if b == nil {
		return nil, &sys_error.InternalError{Cause: errors.New("biz.Book.Options: receiver b (*biz.Book) is nil")}
	}
	if ctx == nil {
		return nil, &sys_error.InternalError{Cause: errors.New("biz.Book.Options: request context (ctx) is nil")}
	}
	if req == nil {
		return nil, &sys_error.InternalError{Cause: errors.New("biz.Book.Options: options request (req) is nil")}
	}
	if req.Planet == nil {
		return nil, &sys_error.InternalError{Cause: errors.New("biz.Book.Options: planet reference (req.Planet) is nil")}
	}

	orm := &model.Book{}
	records, err := orm.OptionsByPlanetID(ctx, req.Planet.ID)
	if err != nil {
		if errors.Is(err, model.PlanetNotFoundErr) {
			return nil, sys_error.BookPlanetNotFoundErr
		}
		return nil, &sys_error.DatabaseError{Cause: err}
	}

	books := make([]Book, 0, len(records))
	for _, record := range records {
		books = append(books, Book{
			ID:            record.ID,
			Title:         record.Title,
			Sort:          record.Sort,
			DisplayStatus: record.DisplayStatus,
		})
	}
	return books, nil
}

由控制器组装 DTO 并注册路由

将 Options 追加到现有书籍控制器，与 Create、List 同文件。使用已有的 reqBook、respBook 等导入和统一响应方法。显式初始化响应切片，保证空书单编码为 []。

追加函数controller/v1/book/book.go 
// Options 绑定天体 ID, 并返回目录管理页使用的书籍选项.
func Options(c *gin.Context) {
	req := &reqBook.OptionsReq{}
	respBody := &resp_body.RespBody{}
	if err := c.ShouldBindJSON(req); err != nil {
		respBody.ValidateError(err)
		c.JSON(http.StatusOK, respBody)
		return
	}

	bookBiz := &biz.Book{}
	books, err := bookBiz.Options(c.Request.Context(), req)
	if err != nil {
		var dbErr *sys_error.DatabaseError
		switch {
		case errors.Is(err, sys_error.BookPlanetNotFoundErr):
			respBody.BookPlanetNotFoundError()
		case errors.As(err, &dbErr):
			respBody.DBError(dbErr)
		default:
			respBody.InternalError(err)
		}
		c.JSON(http.StatusOK, respBody)
		return
	}

	options := make([]respBook.OptionResp, 0, len(books))
	for _, item := range books {
		options = append(options, respBook.OptionResp{
			ID:            strconv.FormatInt(item.ID, 10),
			Title:         item.Title,
			Sort:          item.Sort,
			DisplayStatus: item.DisplayStatus,
		})
	}
	respBody.Success(map[string]any{"books": options})
	c.JSON(http.StatusOK, respBody)
}

Postman 验收

使用 POST {{base_url}}/v1/book/options，Authorization 选 Bearer Token 并填入已登录管理员的 JWT。Body 选 raw → JSON。示例 ID 仅用于说明；联调时先用天体列表接口取得实际 ID。以下场景均核对 HTTP 200 响应中的业务码。

场景预期结果
选择有可见书和隐藏书的天体，另一个天体也有书200，仅包含当前天体的全部书籍，两种状态均返回；按 sort、id 升序，书籍 ID 带引号。
选中一本尚未导入目录的书所属的天体200，响应的 books 中包含这本书。
选择已创建且没有书籍的天体200，data 为 {"books":[]}。
提交格式正确、库中不存在的天体 ID20102，message 为“所选天体不存在,请刷新天体选项”，data 为 {}。
缺少 planet、传入 {"planet":{}}，或把 ID 写成数字、"0"、"-1"、"abc"10101，由 ShouldBindJSON 返回绑定或校验错误。
选择有历史 sort = 0 记录的天体200，该书排在正排序值之前，sort 为数字 0。
移除 Bearer 令牌，或使用已过期且签名有效的令牌缺失令牌返回 20004，令牌过期返回 20003。

数据库查询或提交失败时沿用 10201。开发完成后，可在后台工程根目录运行 go test ./... 检查各包，并使用上述场景核对接口行为。
