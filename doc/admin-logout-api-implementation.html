POST /v1/admin/logout

退出当前管理员会话

管理员点击确认退出后，服务端撤销此次请求携带的令牌。关键情形是旧会话 A 的退出还在处理中，同一账号已经登录取得 B。退出事务须在写入前核对令牌摘要，让 B 继续有效。

前后端登出契约 · 现有改密与会话撤销实现

请求与响应

前端通过现有请求实例调用 request.post('/v1/admin/logout')。浏览器经开发代理时显示 /api/v1/admin/logout。请求体为 0 字节，无路径参数或查询参数，Content-Type 可省略。管理员 ID 和令牌摘要均由鉴权中间件提供。Postman 选 Body → none，在 Authorization → Bearer Token 填入令牌原文。

沿用 HTTP 200 和统一响应体。所有分支的 data 都是空对象 {}。鉴权中间件已设置 Cache-Control: no-store。

成功表示服务端已提交撤销。仍在 JWT 有效期内的同一令牌再次退出，返回 20004。两次调用后的会话状态相同，前端可依据各自的响应走相应的清理流程。

与改密共用锁内的会话核验

现有 AdminAuth.Handle 已在 JWT 和数据库会话验证成功后写入 CurrentAdminID(c)、CurrentAdminTokenDigest(c) 所读取的值。后者是对本次请求的原始 Bearer 令牌计算的 32 字节 SHA-256 摘要。登出控制器可以直接使用这两个上下文值。鉴权中间件 · 上下文读取函数

锁定管理员，只清空本次会话的令牌摘要

为 model.Admin 增加 RevokeSession。在 READ COMMITTED 事务中按主键执行 SELECT ... FOR UPDATE，只读取 id 和 token_hash。锁内核验通过后，由同一事务按锁定行的主键显式写入 token_hash = '' 并检查影响一行。提交成功后才向控制器返回成功。现有管理员模型

登录使用的 UpdateTokenHash() 以密码摘要作为更新条件。A 和 B 可以由同一密码先后登录，所以单靠这个条件无法判断库中当前保存的是哪一枚令牌。此处需要比较的是请求 A 的摘要与行内最新的 token_hash。

并发次序服务器结果
A 的请求已通过鉴权，B 的登录先写入新摘要A 拿到行锁后读到 B 的摘要，返回 20004。B 继续正常访问。
A 先锁行并成功提交，随后 B 登录A 返回 200。管理员可以用原密码登录取得 B，B 的摘要由登录接口写入。
两个标签页持同一令牌 A，同时确认退出一次返回 200，另一次在入口鉴权或锁内核对得到 20004。之后 A 发起的受保护请求均失去授权。
改密先提交，或登出先提交先提交的一方已清空令牌摘要；另一方使用 A 时得到 20004。若登出先完成，后到的改密不会写入新密码。

撤销作用于后续鉴权。已经通过入口鉴权的在途请求可能继续执行；改密和登出之所以能识别这段时间内的变化，是因为两者在写入前还会锁行复核会话。

业务层把撤销结果映射到已有错误

biz.Admin.Logout(ctx, sessionDigest) 从接收者取已鉴权管理员 ID，调用模型并转换错误。该操作没有业务响应字段，也无需新建请求或响应 DTO。使用现有表和业务码即可。管理员业务实体 · 响应码与包装器

业务码来源与含义
200本次匹配的会话已撤销，事务已提交。
20003入口鉴权发现签名有效的 JWT 已过期。
20004缺失或无效令牌、账号记录消失、令牌摘要已清空或与当前会话不符；沿用公共鉴权错误。
10201开启事务、锁行查询、更新或提交报错，或目标行数异常。固定文案为“数据库操作失败,请稍后重试”。
500库中非空令牌摘要格式损坏等内部故障。固定文案为“服务暂时不可用,请稍后重试”。
10101全局请求体中间件可在进入控制器前拒绝超限或读取失败的请求。正常的零字节请求直接通过。

退出按钮怎样处理服务器结果

用户取消确认时直接关闭弹窗。确认时先记录发起请求的令牌，再调用接口，并在等待期间锁定按钮。会话需要保留到请求发出，因为现有 Axios 拦截器会从 Store 读取令牌、设置 Authorization 头。顶栏退出入口 · 公共请求实例

  • 200　若本页仍使用发起请求时的令牌，清理会话并调用 router.replace({name: 'login'})。其他标签页只要继续用 A，下一次访问受保护资源也会失败。
  • 20003 / 20004　由现有公共鉴权拦截器比对请求令牌、处理会话并跳转，按钮处理函数到此结束。
  • 服务端故障、断网或超时　若仍为原会话，按用户意图清理本机凭据并返回登录页，提示“本机已退出，未能确认服务器会话是否已撤销”。响应丢失时，事务可能已经提交。
  • 等待期间已切换到 B　忽略 A 的迟到反馈和跳转。跨标签页按 Store 已有的令牌比对保留新凭据。登出请求归属于顶栏主动退出流程；改密成功和公共鉴权失败继续直接使用本地清理方法。会话清理与跨标签页保护
